# Análise de Dados com Python

## Projeto em destaque: reclamações de passageiros

[Ver análise completa de 2025](reclamacoes-aereas/README.md) · [Abrir notebook](reclamacoes-aereas/analise_reclamacoes_aereas.ipynb)

Análise de **103.340 registros públicos da ANAC / Consumidor.gov.br** com Python, Pandas e Matplotlib. Inclui inspeção de qualidade, tratamento de tempos negativos, indicadores com denominadores explícitos, três gráficos e tabelas reproduzíveis.

- **31,77%** dos registros concentram-se nos três problemas mais frequentes.
- **67,99%** de resolução entre reclamações com avaliação de desfecho, que cobrem **50,37%** da base.
- **Dezembro:** 10.723 registros e aumento de 25,78% sobre novembro, sem atribuição de causa.
